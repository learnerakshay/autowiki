Scope: Shared live Wiki generation status used by Workspace and `/wiki`; Operate mode. The brief extends the established clean-light AutoWiki system without changing routes or the generated-document reader.

THESIS: Trust is the premium feature. The interface reports only work the backend has actually entered—queueing, repository retrieval, outline planning, combined chapter-and-diagram generation, and persistence—while clearly withholding percentages and completion estimates it cannot know.

OWN-WORLD: Bright white and icy-cyan surfaces, crisp neutral rules, restrained cyan-teal operational signals, indigo reserved for primary actions, Manrope for product and state identity, workhorse sans for explanatory copy, and mono only for repository and job identifiers.

STORY: A user starts one explicit Wiki job, sees the actual repository and current worker boundary, understands when a chapter count is factual, can inspect the opaque job identifier on demand, and arrives at the existing Wiki reader on completion. Missing stage metadata remains a legible pending state rather than invented progress.

FIRST VIEWPORT: Workspace keeps the submission context visible and replaces the generic pending strip with a compact live activity panel. The Wiki route centers a calm generation state with one current-operation hierarchy, an honest indeterminate signal, and no oversized empty preview.

FORM: Brief-pinned established-world extension in Operate mode; the user's narrow, locked clean-light direction explicitly exempts this surface from concept seeding. The signature interaction is a restrained border-and-surface response only when the reported worker stage changes; the continuous line indicates activity, never completion, and is removed entirely under reduced motion so a static segment cannot imply percentage.
